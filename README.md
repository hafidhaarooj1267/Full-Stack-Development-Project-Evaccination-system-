E-Vaccination Management System is a web-based platform that replaces manual vaccination tracking with a digital system. It helps parents never miss their child's vaccination schedule and assists hospitals in managing appointments efficiently.

Key Features:
- Parent: Register children, book appointments, view vaccination history, download certificates
- Hospital: Manage appointments, update vaccine stock, mark vaccination status
- Admin: Manage parents/hospitals, view all appointments, generate reports

Tech Stack:
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP (Procedural)
- Database: MySQL
- Local Storage for demo mode
- Fully responsive design

This project is built for a university assignment and demonstrates complete CRUD operations, role-based login, and secure session management.
